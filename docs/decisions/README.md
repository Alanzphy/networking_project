# Decisions / ADR

Esta carpeta guarda decisiones tecnicas importantes en formato ADR ligero.

ADR significa Architecture Decision Record. Sirve para explicar que se decidio, por que se decidio y que consecuencias tiene.

## Cuando crear un ADR

Crear un ADR si el cambio:

- Modifica VLANs, subredes o bloque IP.
- Cambia el calendario oficial.
- Cambia la capacidad maxima simultanea.
- Agrega una red nueva.
- Cambia reglas de acceso entre roles.
- Decide entre alternativas importantes como equipo rentado, BYOD, olas o cableado temporal.

## Nombre de archivo

```text
ADR-###-nombre-corto.md
```

Ejemplos:

```text
ADR-001-red-a-23.md
ADR-002-camaras-inalambricas.md
ADR-003-plan-b-capacidad.md
```
