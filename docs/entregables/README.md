# Entregables

Esta carpeta contiene documentos redactados para entrega formal, derivados de la fuente de verdad SDD ubicada en `docs/`.

## Relacion con la fuente SDD

Los entregables no reemplazan los documentos base. Si cambia una decision tecnica, primero debe actualizarse la fuente correspondiente:

- `00-fuente-de-verdad.md`
- `01-arquitectura-red.md`
- `02-eventos-escenarios.md`
- `03-validacion-operacion.md`
- `04-espacios-fisicos.md`

Despues de actualizar la fuente, se ajusta el entregable formal.
